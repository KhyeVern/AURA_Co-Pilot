# Security Policy

## Supported Versions

Security updates are applied to the `main` branch of the AURA Co-Pilot project.

| Version | Supported          |
| ------- | ------------------ |
| 3.0.x   | :white_check_mark: |
| < 3.0   | :x:                |

---

## Reporting a Vulnerability

If you discover a potential security vulnerability within **Mercedes AURA Co-Pilot**, please report it responsibly:

1. **Do NOT open a public GitHub issue.**
2. Send an email detailing the vulnerability to **`khyevernng@gmail.com`**.
3. Include:
   - Description of the issue and potential impact
   - Step-by-step instructions or proof-of-concept to reproduce
   - Component affected (Web Dashboard, CV Tracker, Biometric Simulation)

---

## Response Process

- **Acknowledgement:** We aim to acknowledge receipt of your report within 48 hours.
- **Assessment:** We will validate and assess the severity of the issue.
- **Fix & Disclosure:** Once a fix is verified, a release will be published along with appropriate security disclosure notes.
